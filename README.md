# QA Copilot IA

Sistema Inteligente de Asistencia para Testing de Software basado en Orquestación Agéntica y Memoria Persistente.

## 🚀 Descripción
QA Copilot IA ayuda a los equipos de QA a analizar historias de usuario, generar casos de prueba, detectar defectos y aprender de resultados históricos.

## 🧠 Arquitectura
- Frontend: React + Vite
- Backend: Node.js + Express
- Base de datos: MongoDB Atlas
- Orquestación IA: LangChain
- Seguridad: JWT
- Deploy: Vercel (frontend) + Railway (backend)
