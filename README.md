Sistema Inteligente de Asistencia para Testing de Software basado en **Orquestación Agéntica** y **Memoria Persistente**.

---

## 🚀 Descripción
QA Copilot IA ayuda a los equipos de QA a:
- Analizar historias de usuario
- Detectar ambigüedades y requisitos faltantes
- Generar casos de prueba automáticamente
- Crear datos de prueba válidos e inválidos
- Analizar defectos reportados
- Aprender continuamente de resultados históricos

---

## 🏗️ Arquitectura
- **Frontend:** React + Vite (deploy en Vercel)
- **Backend:** Node.js + Express (deploy en Railway)
- **Base de datos:** MongoDB Atlas
- **Orquestación IA:** LangChain
- **Seguridad:** JWT + validación de inputs
- **Contenedores:** Docker para portabilidad
